# CV Interactivo - Daniel Izquierdo

Este proyecto es una landing page personal en formato de currículum interactivo.

**Tecnologías utilizadas:**
* HTML5 semántico
* CSS puro (diseño responsive en negro, azul y rosa)
* JavaScript (efecto máquina de escribir)
